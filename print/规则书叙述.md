# 一、这是什么

《创界山·活人认证》是一款桌面多人策略游戏。玩家扮演{{player}}，沿{{path}}向上攀登，争夺{{peak}}的「活人席」。

**但登顶不是胜利。**

抵达{{peak}}只是拿到入场券。{{peak}}设有「活人认证」：待认证者必须被在场的其他玩家**当场验明是活人**，集齐足够签印才算坐上一次活人席。

**坐上活人席也不结束这一局** —— 你会回到{{path}}起点，还能再登顶、再取席。整局在回合上限处结束，按「席位数」与「你离{{peak}}的距离」决出胜负。

这意味着最后一步不是拼数值，而是**说服在场的人**。你可以说服他们，也可以接受他们的审视。

# 二、一局怎么玩

## 回合结构

一个「回合」指**所有存活玩家各行动一次**。每个回合依次进行：

1. **天机**：翻开一张天机牌，对全场生效。
2. **行动**：按**开局随机决定的行动顺序**依次，每人**一次行动**，三选一——**行棋**（掷六面骰前进）、**问天**（掷二十面指令骰执行指令）、**行事**（打出一张{{deck}}或发动能力）。
3. **结算**：结算落点的地形效果。
4. **裁牌**：手牌超出{{hp}}上限则弃至上限。
5. **经济**：存活玩家各得一枚{{resource}}。
6. **牌库循环**：牌库抽空时，弃牌堆洗回牌库。
7. **山议**：按间隔召开，全员匿名投票放逐得票最高者。
8. **认证**：若有待认证者，结算本轮认证。

## 地形

{{path}}上分布着六种格位。**地形效果只在「停留」时触发** —— 移动是「跳到位」：途中经过的格子**不结算**（经过{{boon}}不触发、经过对手也不对峙）。支路是显式选择，跳到支路终点后才结算那一格。

| 格位 | 效果 |
|---|---|
| {{plain}} | 无 |
| {{boon}} | 立即抽 2 张{{deck}}，{{resource}} +1 |
| {{hazard}} | 翻开{{deck}}堆顶 1 张判色：红 = 安全通过；黑 = {{hp}} -1 |
| {{rift}} | 你站在这一格时可花 2 {{resource}}放置「封路印」，**后来者**经过时需判定，失败则停 1 回合 |
| {{gate}} | 硬门槛，两条通过路径（见下） |
| {{peak}} | 进入待认证区 |

### {{boon}}

停下即得：抽 2 张{{deck}}，并立刻 {{resource}} +1。抽牌与进账都在你落格的瞬间完成。

### {{hazard}}

**翻开{{deck}}堆顶 1 张牌**判颜色（红 > 黑）：

- **红** = 安全通过，什么都不发生；
- **黑** = {{hp}} -1 —— 你的这一次行动已经用完，下一次机会要等下一回合。**若 {{hp}} 因此归零，你进入「力竭」**（见下文「力竭」一节）。

这张翻开的牌**从堆顶取出**进入弃牌堆（红黑皆然）—— 不是复制，也不是从你手牌里翻。
翻牌**不可操控**，也不消耗手牌。若牌堆与弃牌堆都空（理论上不会发生，因为牌库会循环）⇒ 直接安全通过。

### {{rift}}

{{rift}}本身不惩罚谁，它是**战场**：

- **你站在这一格时**可花 **2 {{resource}}** 在这一格公开放置「封路印」（印**公开可见**）；
- **后来者**经过该格都需判定（**放置者当次不受影响**），**失败则停 1 回合**。

### {{gate}}

每座{{gate}}是硬门槛，提供两条通过路径：

- **付费通道**：支付该格标明的{{resource}}数额（见棋盘格面）立即通过；
- **试炼通道**：抽一张「试炼牌」执行其要求（如展示 2 张同色手牌、出示 4 枚资源、掷指令骰 ≥ 15）。失败则退 1 格并被封口；**部分试炼失败后本关改为付费**（只能付钱过关，付不起则判未通过放行）。

试炼牌是**公开信息**，抽取时全场可见；已通过同座{{gate}}的试炼牌不再被抽取。
{{gate}}试炼由试炼主持者（上帝）判定，判定标准写在牌面上 —— 它与「活人认证」是两件事，不要混淆。

### {{peak}}

踏上{{peak}}即进入**待认证**区（见「活人认证」一节）：登顶只是入场券，真正的胜负在认证之后。

## 对峙

若你与对手落在**同一格**，进入对峙：双方**各自从手牌选 1 张牌**（选牌对对方不可见），选完后**同时揭晓**。

- 先比**颜色**：红 > 黑。
- 同色比**点数**：A 最大、2 最小。
- 颜色与点数都相同 → **平局**：双方都不后退，各弃 1 张。
- 分出胜负：**败者后退 1 格并抽 1 张牌**；胜者不额外获益。
- 任一方**手牌为空** → 该方自动落败：后退 1 格，不抽牌。

两张亮牌在比较后**留在场上公开**，直到本回合结束。

## 山议与放逐

山议是公开的社交博弈。得票最高者被放逐出局。

**三条例外**：

- **放逐下限**：场上存活人数不得少于三人。这保证活人认证永远有认证人在场。
- **凭证**：被提名者可花三枚{{resource}}出示凭证，免疫本次放逐。凭证公开可见。
- **仲裁者否决**：仲裁者可消耗特权否决一次放逐。

**三人局的特殊处理**：三人局若照常放逐，存活人数将低于下限，因此改为「**山议裁定**」——得票最高者扣两枚{{resource}}，不淘汰。并列最高则各扣一枚。

## 活人认证

抵达{{peak}}者进入「待认证」，并公示所需签印数。其他每位玩家每轮可以做一件事：

- **签印**：直接贡献一枚签印。
- **质疑**：提出三道题，待认证者逐题作答，答对两题即通过。
- **弃权**：本轮不用机会。

### 判罚权与申诉

认证人判定「通过 / 不通过」。但判定权不是无限的：

- 认证人必须**先公开判定标准**，本轮内不得更改。
- 判「不通过」时，待认证者可花两枚{{resource}}**申请复议**，由第三方玩家投票裁定；平票视为复议成功。
- 待认证者可**拒绝回答明显不可当场验证的题目**（如「你昨晚梦到了什么」），由第三方裁定是否换题。

### 质疑的成本

**发起质疑即扣一枚{{resource}}，无论成败。** 若待认证者答对两题，质疑者还要**再扣一枚**。

这让恶意质疑有真实代价：你想反复阻拦一个人，就得反复掏{{resource}}——而{{resource}}同时是你移动和改判定的硬通货。

### 认证轮次

认证最多两轮。两轮仍未达成，待认证者退回{{path}}六成位置，本次登顶作废。

### 双人互验

若两人同时登顶，双方互相出题认证，所需签印降为一枚——互相证明对方是活的。

### 认证通过之后

集齐签印 ⇒ **获得一个活人席**，你回到{{path}}起点，可以再次登顶、再次取席；你仍在场上，可以继续为别人签印。

活人席**没有数量上限** —— 整局能发出多少席，取决于大家认证得多快。

### 印记

达成终局目标者获得**印记**：所需签印数减半（向上取整）。印记不绕过终局，仍须走完认证流程。

## 力竭（体力归零）

**{{hp}} 归零的那一刻，你不会出局——你「力竭」了。** 放逐（山议投票）是本局唯一的出局通道；力竭是可逆的重伤。

力竭持续到**下一次回合末之后再过一个回合末**（约两个回合末之间的时长），期间：

- 手牌上限**减半**（向上取整）——下一次回合末裁牌时生效；
- 行棋的骰面**减一**（至少走一格）；
- **不能发动主动型身份被动**；
- 认证时**不能发起质疑**（签印与弃权照常；你自己待认证时仍可被质疑、可申诉）。

**三条恢复路径**：等它自然过去（回合末自动倒数）；花**两枚{{resource}}**并占用本手番行动**自我恢复**；或让任意位置的队友花**一枚{{resource}}**占用其手番行动**救援你**。恢复时体力回到**半血**（向上取整）——不是满血，力竭不是回血手段。

## 负面状态

五种负面状态都由牌或关隘施加，**都是临时账，不是永久标记**。它们的扣减点统一在**你自己手番结束时**（力竭除外，它按回合末倒数）——**「N 个手番」指你接下来的 N 个完整手番**；如果你是在自己的手番里中招（例如关隘试炼失败），当前手番剩下的行动也立刻被封，但**不占掉这 N 个的额度**。

- **中毒 N 层**：你手番结束时按层数扣 {{hp}}（2 层扣 2 点），然后层数减 1。扣到 0 ⇒ **力竭**。中毒是唯一能把你打进力竭的持续伤害。
- **减速 N 层**：你下一次行棋的骰面少走 N 格（**至少走 1 格**；与力竭的减 1 格叠加，可同时 −2 格），实际被吃掉几格就减几层。
- **封口 N 回合**：被封口的**那一刻**立刻弃 1 张{{deck}}（弃最左边那张，不用你选）；此后 N 个手番内**不能出牌、不能发动身份被动**。行棋、问天、装备造物照做——封口封的是「出手」，不是「走路」。
- **停手番 N 回合**：你的下 N 个手番不能采取任何行动，只能宣告结束手番；但**回合结束照常结算**——收入照拿、地形照触发、裁牌照做。停手番是「少一次行动」，不是「被抹掉一回合」。若你正卡在{{gate}}或裂隙的待决面上，那个选择**也必须照做**（否则你会永远出不去）。
- **免疫 X N 回合**：N 个手番内不会再被授予 X。**免疫是预防，不是解药**——已经中的毒照常扣血、照常衰减，免疫只挡新的。它挡的是整件事：被免疫的封口连那一张弃牌也一起免掉。

放逐（山议投票）会把你身上的负面状态与免疫窗**一并清空**——反正你已经出局了。

# 三、牌面与实体件

## {{deck}}（卡牌）

标准扑克尺寸，六十三乘八十八毫米，含三毫米出血与三毫米圆角，自带现成套牌壳即可收纳使用。

每张{{deck}}有点数（A 为十四，最大），对峙时先比颜色（红胜黑），同色比点数。

## {{path}}

四张 A4 拼接为 A2 幅面，亦提供 A3 单张版本。

## 筹码

直径二十五毫米，或直接使用硬币替代。

# 四、获胜

整局在**回合上限**处结束（见规模表），此时按**终局得分**排名：

> **终局得分 = 活人席数 × 活人席权重 − 距{{peak}}的格数**

一句话：**一个活人席抵得上爬半座山**（权重见规模表）。

- 得分高者胜；
- 得分相同 → 已获签印更多者优先；
- 仍相同 → {{resource}}更多者优先；
- 完全相同 → 并列胜出。

**拿席多不等于稳赢** —— 早早封顶的人已经回到{{path}}起点，位置会被后来者追平；反之，一直逼近{{peak}}的人靠位置也能压过只拿到一席的人。
