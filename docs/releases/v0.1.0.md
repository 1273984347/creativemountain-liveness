# v0.1.0 — 首个公开版本

《创界山·活人认证》(Creativemountain Liveness) 2026 重制版的首次公开发布：
一套规则引擎同时产出**离线单文件 HTML**（数字轨）与**可打印 PDF/SVG**（实体轨），
十四道门禁保证双轨不漂移。

## 核心内容

- **规则引擎**：状态 / 回合机 / 58 算子 / 16 谓词 / 8 种终局；完整的「活人认证」闭环
  （签印 · 质疑 · 复议 · 合规检查 · 双轮上限 · 双人互验 · 印记减半）；山议放逐下限 3；
  五类负面状态（中毒 / 减速 / 封口 / 停手番 / 免疫）与力竭；可选 AI 补位座位（引擎层拒绝其认证动作）。
- **四套主题**：仙侠·2026（基准）/ 科幻·AI 纪元 / 融合·道械双修 / 都市·异能纪 —— 共用一套 schema 与 18 叶术语契约，
  界面上不硬编码任何一套主题的词。
- **数字轨**：单文件、离线、双击即玩；另有 React + Vite 的主屏原型（实时看板 / 认证高潮 / 结算排名 / 开局教学）。
- **实体轨**：主题 → IR → SVG → HTML → PDF 管线，产出规则书、棋盘、48 张卡、8 张身份牌、4 张阵营牌、
  认证题卡与筹码；规则书规模表的每个数字都带可机读的溯源标记。
- **质量门禁**：`npm run gate` 一条命令跑十四道门（类型 / 测试 / 文档漂移 / 构建 / 主题与 IR 契约 /
  双轨一致性 / 主题差异化 / 规模与平衡模拟 / 浏览器端到端 / 试炼通过率 / 位次极差回归 / 余量阈值回归 /
  浏览器 UI 走查），任一失败即非零退出；每道门都配「违例必红、恢复必绿」的常驻负样本。
- **平衡**：多 seed 确定性模拟与入库基线快照；「登顶即胜」的首达峰顶胜率从约 77% 降到 17–35%。
