# B79 句子层主题词接线与 face 15 措辞 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把引擎与 UI 产出的中文句子里的基准仙侠词（灵枢/关隘/山道/峰顶/灵力）换成占位符，由渲染层按主题词表展开；同时补上 B78 承诺却从未实现的 `terms ↔ glossary` 等值守卫，并结账指令骰 face 15 的措辞债。

**Architecture:** 三层分工不变——引擎只发「机制事实 + `{leaf}` 占位符」，`engine/core/theme-text.ts` 是唯一替换实现，四个显示出口（日志 / notice / alert / 面板按钮）负责展开。句子层的取词只认 `ThemeTerms`（闭合、门⑤ 逐叶校验），`glossary` 退回印刷层专用对照表，两边由门⑤ 五键判等钉住。

**Tech Stack:** TypeScript 5.6 strict（`noUncheckedIndexedAccess` + `exactOptionalPropertyTypes` + `verbatimModuleSyntax`，**无 `allowJs`**）、Node 24（`.mjs` 可直接 import `engine/*.ts`；`.ts` import `.mjs` 需同目录 `.d.mts`）、`node --test`、esbuild、自研 13 道门禁 `tools/gate.mjs`。

**Spec:** [docs/superpowers/specs/2026-11-16-b79-句子层主题词接线-design.md](../specs/2026-11-16-b79-句子层主题词接线-design.md)（r1.2，已批准）。**执行时两份都要读**——本计划论证自该规格，规格里的裁定表（§0.3 Q1–Q6）是不可重开的前提。

## Global Constraints

每个任务的隐含要求，逐条来自规格：

1. **零行为红线**（§1）：`node tests/sim/run.mjs --games 30 --check` 的 stdout 必须**逐字节**与 T0 抓的基线相同；`npm run release` 的 100 组重扫逐组比对必须 ≡ `docs/baselines/trial-reserve-scan-B77.json`。数字漂移 ⇒ **停下按 E116 归因**（确定性重放里数字差异就是行为差异），不重基线、不放宽任何锁（含 5.5pp 位次极差参考线）。
2. **占位符集合**：只有 `{resource}` `{gate}` `{path}` `{peak}` `{hp}` 五个（§4.4）。`{deck}` 不存在——`scifi-ai` 的 deck 词是「指令」，与规则词「问天指令骰 / 第 N 条指令」同形。
3. **R1 扫描域** = `engine/**` + `web/**`，**不含** `build/**`（印刷层取词归门⑤⑥⑦ 管，§5.4）。该域内**主题词字面量白名单必须是空集**（§5.2）。
4. **共享子串一字不许动**（§5.3）：`GATE_FALLBACK_CLAUSE = '本关改为付费'`、`GATE_PAY_FAIL_CLAUSE = '仍未付足则判未通过，退 1 格并被封口'`——只许改名词位（`关隘` → `{gate}`）。
5. **测试写法分工**（§5.1）：标题与注释用中性机制词；**基准主题（xianxia2026）断言里的「灵枢」保留**（它是展开结果）。不许把基准断言改成 `{resource}`。
6. **注释与文档里的历史词不动**（§2）：`engine/web` 有 212 行注释含这些词，它们是施工证据；`themes/**` 与 `docs/**` 的世界观正文（docs 实测 3804 处「灵枢」）不在本批范围。
7. **非基准主题的 `theme.json` 是生成物**：改数据只能改 `build/theme-data/<id>.mjs`，然后 `node build/build-themes.mjs` 回灌；`themes/xianxia2026/theme.json` 是基准源，手工改。改完必须 `tests/build/themes-generated.test.ts` 绿。
8. **门⑥ 读 `print/<id>/ir.json`** ⇒ 任何影响 IR 的任务，提交前先 `npm run print`（它逐主题跑 build-ir + 实体件）。
9. **每次提交一个任务**，前缀 `feat(B79)` / `test(B79)` / `docs(B79)`；提交信息里凡产物文字变化（face 15、平衡报告标签）必须单列，不得混入「零行为」主张（§1 例外条款）。
10. **纪律**：不 `--no-verify`、不 `git add -A`（逐文件 stage）、门禁脚本直接 spawn（不接管道）。

```ts
// 句子层占位符的唯一替换实现（B79 §4.1）。
//
// 为什么用占位符而不是「把 terms 注进引擎」：`State` 里没有 themeId，engine/** 也不 import
// 任何主题数据（架构事实）；注词表要改 40 个调用点，还会把 `uiAllows` 的 null 判据与签名
// 重新耦合。占位符只多一个纯函数，引擎继续只报机制事实（B78 P1 的延伸）。
//
// ⚠️ 集合里**没有 deck**：scifi-ai 的 terms.deck 是「指令」，与规则词「问天指令骰 / 第 N 条指令」
//   同形（规格 §4.4）——接进句子层会把合规实现判红。
import type { ThemeTerms } from '../types/theme.ts';

/** 允许出现在玩家可见句子里的占位符（顺序稳定，供守卫与文档引用）。 */
export const TERM_TOKENS = ['resource', 'gate', 'path', 'peak', 'hp'] as const;

/**
 * 把 `{leaf}` 换成主题词。缺叶**抛错**，不静默保留占位符——
 * 漏印 `{path}` 给玩家看，和印出错的主题词是同一类缺陷（B78 页脚假话的形状）。
 */
export function expandThemeWords(raw: string, terms: ThemeTerms): string {
  let out = raw;
  for (const token of TERM_TOKENS) {
    const value = terms[token];
    if (typeof value !== 'string' || value.length === 0) {
      throw new Error(`terms.${token} 缺失或非字符串 ⇒ 无法展开 {${token}}（句子：${raw}）`);
    }
    out = out.split(`{${token}}`).join(value);
  }
  return out;
}
```

```js
// 句子层主题词的字面量归属扫描（B79 §5 R1/R2）。
//
// 为什么抽成模块：B51 的教训——扫描逻辑写死在测试里 ⇒ 负样本只能另写一份近似实现 ⇒
// 测的是负样本自己。正负样本必须共用同一函数。
//
// 为什么不用 tests/gates/repo-scan.ts：它的匹配器硬编码 TOKENS（CM_SELFTEST/--selftest），
// 且 ALLOWED_ROOTS 只放行 tests/ 与 docs/批次 ⇒ 拿它扫 engine/web 会扫到 0 文件。
import { readFileSync, readdirSync, statSync } from 'node:fs';
import { join, resolve } from 'node:path';

/** 本批接线的五个叶（`deck` 排除：同形词「指令」，规格 §4.4）。 */
export const SENTENCE_LEAVES = ['resource', 'gate', 'path', 'peak', 'hp'];
export const SENTENCE_DOMAINS = ['engine', 'web'];

/** 禁字表：从主题数据派生，不手抄 ⇒ 第五套主题一进来就自动纳入。 */
export function leafWordsFromThemes(root = 'themes') {
  const words = new Map();
  for (const entry of readdirSync(resolve(root))) {
    const p = resolve(root, entry, 'theme.json');
    let terms;
    try { terms = JSON.parse(readFileSync(p, 'utf8')).terms; } catch { continue; }
    if (typeof terms !== 'object' || terms === null) { continue; }
    for (const leaf of SENTENCE_LEAVES) {
      const v = terms[leaf];
      if (typeof v === 'string' && v.length > 0) {
        if (!words.has(v)) { words.set(v, { word: v, leaf, themes: [] }); }
        words.get(v).themes.push(entry);
      }
    }
  }
  return [...words.values()].sort((a, b) => a.word.localeCompare(b.word));
}

const SOURCE_EXT = /\.(ts|tsx|mjs|mts)$/;

function listSources(dir) {
  const out = [];
  for (const e of readdirSync(dir)) {
    const p = join(dir, e);
    if (statSync(p).isDirectory()) { out.push(...listSources(p)); }
    else if (SOURCE_EXT.test(e)) { out.push(p); }
  }
  return out;
}

/** 注释行不算：本批只管文案的**来源**，历史施工注记是证据（规格 §2）。 */
function isComment(line) {
  const t = line.trim();
  return t.startsWith('//') || t.startsWith('*') || t.startsWith('/*') || t.startsWith('·');
}

/** 返回命中清单 `相对路径:行号 「词」 叶=leaf 主题=a,b`。 */
export function scanThemeWords(root, domains, words, whitelist) {
  const hits = [];
  const allowed = whitelist ?? new Map();
  for (const domain of domains) {
    for (const f of listSources(resolve(root, domain))) {
      const rel = f.slice(resolve(root).length + 1).split('\\').join('/');
      readFileSync(f, 'utf8').split('\n').forEach((line, i) => {
        if (isComment(line)) { return; }
        for (const w of words) {
          if (!line.includes(w.word)) { continue; }
          if ((allowed.get(rel) ?? []).includes(w.word)) { continue; }
          hits.push(`${rel}:${String(i + 1)} 「${w.word}」 叶=${w.leaf} 主题=${w.themes.join(',')}`);
        }
      });
    }
  }
  return hits;
}

/** R1 域的白名单：**必须恒为空集**（规格 §5.2）。加条目要先改规格，不能先改这里。 */
export const SENTENCE_WHITELIST = new Map();

/** R2：alert 参数里**直接**出现占位符字面量 = 忘了展开（只判字面量，不判「必须含展开函数」，避免 `alert(t(x))` 误报）。 */
export function scanUnexpandedAlerts(root) {
  const hits = [];
  for (const f of listSources(resolve(root, 'web'))) {
    const rel = f.slice(resolve(root).length + 1).split('\\').join('/');
    readFileSync(f, 'utf8').split('\n').forEach((line, i) => {
      if (isComment(line)) { return; }
      if (/alert\([^)]*\{(?:resource|gate|path|peak|hp)\}/.test(line)) {
        hits.push(`${rel}:${String(i + 1)} ${line.trim()}`);
      }
    });
  }
  return hits;
}
```
