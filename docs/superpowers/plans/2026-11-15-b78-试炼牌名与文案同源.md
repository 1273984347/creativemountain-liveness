# B78 · 试炼牌名与文案同源 · 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 48 张试炼牌「牌面说的话」与「引擎判的事」对齐——补 `trials[].name` 走通九站契约链，让 `terms` 真正驱动卡面词表，合并两份指令骰表并钉 20 面快照，删掉试炼卡页脚与规则书里的假话后果，全程零行为变更。

**Architecture:** 三条分工撑住整批：① **引擎只报机制事实、文案归渲染层**（`gate.ts:176` 的既有原则推广到指令骰）；② **同一口径只许一份实现**，每处合并配一条源码字面量归属断言；③ **版面词表与数据词表必须同源**——题面括注、卡面页脚、规则书小节都由 `build/trial-text.mjs` 的派生函数供句，守卫判「逐字包含」而不是判「关键词出现过」。

**Tech Stack:** TypeScript strict（`noUncheckedIndexedAccess` + `exactOptionalPropertyTypes` + `verbatimModuleSyntax`，**无 `allowJs`** ⇒ `.ts` 引 `.mjs` 必须有 `.d.mts`）· `node --test`（测试直接引 `.ts`）· Node 24 类型剥离（`.mjs` import `.ts`，先例 `tools/ir-validate.mjs:15`）· esbuild 单文件 · 13 道门禁 `tools/gate.mjs` · doc-sync C1–C10 · SVG/PDF 印刷链。

 *
 * ⚠️ 越界 / 缺 terms.resource ⇒ 抛错，不返回兜底串（理由见测试文件头）。
 * ⚠️ face 15 的「本回合」是**待裁定措辞**（T0 审计：真值是「1 个手番含本手番剩余」，
 *   见 statuses.ts:126-137 与规格附录 A.4）⇒ 本批照搬现值，改它要走裁定，不在这里顺手改。
 */
export function instructionText(face: number, terms: ThemeTerms): string {
  const row = INSTRUCTION_TABLE.find((x) => x.face === face);
  if (row === undefined) { throw new Error(`instructionText：没有第 ${String(face)} 面指令`); }
  const word = terms?.resource;
  if (typeof word !== 'string' || word.length === 0) {
    throw new Error('instructionText：terms.resource 缺失（主题包词表不完整）');
  }
  return row.text.split(RESOURCE).join(word);
}

/** SVG 里含某串的 <text> 的 y 值（按标签顺序取第一个命中，数值精确）。 */
function yOf(svg: string, needle: string): number | null {
  const i = svg.indexOf(needle);
  if (i < 0) { return null; }
  const m = svg.slice(svg.lastIndexOf('<text', i), i).match(/ y="([\d.]+)"/);
  return m?.[1] === undefined ? null : Number(m[1]);
}

  assert.equal(yOf(svg, '>关隘试炼<'), 11, '类目行保持 pad+8');
  assert.equal(yOf(svg, '>燃朱<'), 18, '标题行 = pad+15');
  assert.equal(yOf(svg, '>展示手里<'), 30, '正文首行 = pad+27');
});

test('空 name ⇒ 整行不渲染、正文起点不随 name 存在与否漂移', () => {
  const withName = trialSvg({ ...TRIAL, name: '赤步' }, 0, GLOSSARY);
