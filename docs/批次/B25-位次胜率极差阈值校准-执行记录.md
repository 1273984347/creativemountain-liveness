# B25 · 位次胜率极差阈值校准（两层口径 + 确定性回归锁）

> 批次号 B25 · 日期 2026-11-08 · 主题：消 B24 登记的 **T2** —— §9.2 的「位次胜率极差 **< 4pp**（8000 局）」口径**改前即不满足**（8 人局独赢口径 4.5pp）⇒ 校准阈值，并让门禁按新阈值**严格判定**。

## 1. 诊断：为什么「< 4pp」不成立

| 观察 | 数据 |
| --- | --- |
| **极差只由单个离群位次决定** | `max − min` ⇒ 其余位次的信息全丢 ⇒ 统计量被离群点绑架 |
| **6000 局**下跨 4 组独立样本（seedBase 1000 / 5000 / 9000 / 13000） | 最大极差 **4.9 / 8.0 / 4.7 / 5.0 pp** ⇒ 噪声跨度 **3.3pp** |
| **2400 局**（拟作门禁规模） | 最大极差 **8.6pp**（4 人档）⇒ 小样本更不可用 |
| 「严格单调」定性红旗 | 2400 局的 **4 人档**、6000 局的 **3 人档**都出现过 ⇒ **噪声能造出严格单调** ⇒ 该判据不可单独当门禁 |
| **24000 局**（大样本） | 各档极差 0.9 / 3.0 / 1.7 / 2.5 / 2.3 / **4.2pp**，**无任何档位严格单调** ⇒ 先手优势已消除，剩余幅度是噪声 |

⇒ 结论：**极差是噪声主导的统计量**；旧口径既没绑定样本量、也没绑定人数档 ⇒ 必须重写。

## 2. 校准后的两层口径

| 层 | 口径 | 阈值 | 用途 |
| --- | --- | --- | --- |
| **统计口径** | ≥ **24000 局**（4 主题 × 6 档 × 1000 局） | 跨档最大极差 **≤ 6pp** | 评审判断「先手优势是否真的存在」 |
| **门禁口径** | **固定 seed 1000** + 每档 100 局（2400 局） | 最大极差 ≤ **11pp** 且最大 **RMS 偏离** ≤ **4.5pp** | **确定性回归锁**（同 seed 同结果 ⇒ 零 flake） |

- 阈值常量集中在 **`engine/core/balance.ts`**（单一事实源）⇒ 规格、报告、门禁三处共用，不再各写一个数字。
- 平衡报告新增「**位次胜率极差（§9.2 验收口径）**」小节：**逐档**给出极差 + **RMS 偏离** + 严格单调标志（RMS 用到全部位次 ⇒ 比极差稳健）。
- 统计量抽成引擎纯函数 `computePositionSpread` ⇒ 报告、门禁、单测**共用同一份实现**。

## 4. 遗留（如实登记）

| # | 现象 | 归属 |
| --- | --- | --- |
| T1 | 8 人档的极差（4.2pp）与 RMS（1.28pp）系统性高于其它档位 | 已知统计性质（max−min 随位次数放大）⇒ 本批并列给出 RMS；阈值若要跨档严格比较须改用 RMS |
| T2 | 门禁第 ⑫ 道只覆盖**固定 seed 的 2400 局**这一个切片 ⇒ 真实恶化若不落在该切片上会漏检 | 本批以「零 flake + 可复现」优先；后续可加**多 seed 轮换**（成本换检测面） |
| T3 | 「严格单调」作为定性信号在小样本下会被噪声造出 | 已从门禁判据降级为**参考标志**（报告仍给出） |

## 5. 复盘

- **阈值口径必须与样本量、档位一起绑定**：旧口径「8000 局下 < 4pp」既没绑定样本量也没绑定档位 ⇒ 在 24000 局的 8 人档上改前就红 ⇒ 判据不可用。
- **极差类统计量是噪声主导**：`max − min` 只用两个点 ⇒ 其余样本的信息全丢 ⇒ 阈值优先用**用到全部样本**的量（RMS / MAE），并把极差并列给出。
- **定性红旗也会被噪声造出**：「位次胜率严格单调」在 3–4 人档的小样本里概率不低 ⇒ 只能当参考，不能单独当门禁判据。
- **门禁要「确定性回归锁」**：直接判一个带噪声的指标 ⇒ 要么永远红、要么随机红 ⇒ 用**固定 seed + 固定局数**（同 seed 同结果 ⇒ 零 flake）承担「策略改坏 ⇒ 指标突变 ⇒ 判红」，把**统计判断**留给大样本口径。
- **阈值要有单一事实源**：规格正文 / 报告 / 门禁三处各写一个数字 ⇒ 必然漂移 ⇒ 集中在 `engine/core/balance.ts`，其余引用。
