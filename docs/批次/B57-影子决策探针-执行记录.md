## 6. 复盘与经验沉淀

- **「不可观测」有时是结构性的，不是缺日志**：对峙在一次调用内立起并结算 ⇒ 再多日志也留不下那一瞬 ⇒ 唯一出路是**引擎在那一刻交出观测点**（只读回调）。⇒ 「加日志」不总是解法。
- **只读观测钩子可以做到行为零变化**：回调不改 state / 不改 log / 不改控制流 ⇒ 报告逐字不变 ⇒ 引擎改动**不必**以行为变化为代价。
- **判据的分母要能被质疑**：峙面样本若混进 answerRate 分母 ⇒ answerRate 会被**虚高**（那 8 条根本无题可问）⇒ 分桶 + 列原因是硬要求，不是形式。
- **白名单要按「数据怎么分词」来建**：词表按整段名建，而分词器按字符类切 ⇒ 间隔号牌名永远匹配不上 ⇒ 白名单必须**用同一个分词规则**把值拆开再入表。
- **「数据侧派生」优于「手抄扩表」**：8 种被动 op 手抄必漏 ⇒ 从主题包派生 ⇒ 主题加新被动时**自动**进白名单。
