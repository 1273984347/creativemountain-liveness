# B50 · 扫描边界与令牌匹配的**独立复核**

> 批次号 B50 · 日期 2026-11-09 · 主题：对 B49 的仓库级扫描做**独立方法**复核（不只信被审的扫描器）⇒ 顺带清掉一处「文件名级」残留。

## 1. 复核方法（与被审扫描器**不同**）

用 `git grep -in -E "cm_selftest|selftest|skip.gate|skip.rescan"`（**大小写不敏感 + 子串**）与 `git grep -n -E "CM_SELFTEST|--selftest"`（**区分大小写的精确令牌**）两套口径独立核验，并逐项检查扫描器的跳过目录 / 大文件 / 二进制 / CI 路径清单。

## 2. 结论

| 项 | 结论 | 证据 |
| --- | --- | --- |
| 精确令牌（`CM_SELFTEST` / `--selftest`） | **允许区外零命中** | 精确令牌 grep 的命中仅落在 `docs/批次/*.md`（历史记录）与 `tests/gates/*` |
| 生产代码（`tools/`、`engine/`、`build/`、`web/`） | **无命中** ✓ | 同上 |
| npm scripts | **无命中** ✓ | `package.json` 内 selftest 命中数 = 0 |
| CI | **无命中** ✓ | 仓库当前**没有** CI 目录（`.github`/`.gitlab`/`.circleci` 等均不存在）⇒ 该检查为空转 |
| 跳过目录 | `print/`、`dist/` **无跟踪文件** ⇒ 不会藏生产代码 ✓ | `git ls-files print dist` 计数 = 0 |
| 大文件 | **无** > 2MB 的跟踪文件 ⇒ 不会因体积上限漏检 ✓ | 扫描为 0 |

## 3. 发现并修掉的一处缺口（**文件名级**）

宽口径 grep 显示允许区外仍有 3 处命中 —— 命中的是**包装器文件名**（`release-check-selftest.mjs`），不是令牌 ⇒
令牌级无漏检，但「生产代码/活文档**引用了**自检入口的文件路径」仍属边界外的引用 ⇒
⇒ 已把允许区外的**文件名引用**改写为中文描述（「tests/gates/ 下的自检包装器」），语义与指向不变；`tests/` 侧的真实路径引用**保持不动**（允许区）✓。

## 4. 遗留（如实登记）

| # | 现象 | 归属 |
| --- | --- | --- |
| T1 | 令牌匹配**区分大小写** ⇒ `cm_selftest` / `--SELFTEST` 这类变体不会被命中 | 现状：仓库内无此类写法；若日后出现 ⇒ 建议把 TOKENS 改成大小写不敏感正则 |
| T2 | CI 检查目前是**空转**（仓库无 CI 目录） | 若日后引入 CI，路径清单需同步扩充（`.github/actions/` 等已在 `.github` 递归内） |
| T3 | 跳过目录含 `print/`、`dist/`（当前无跟踪文件）与 `node_modules/`、`.git/` | 合理（依赖/产物/版本库）；若日后把源码放进这些目录 ⇒ 需重新评估 |

## 5. 复盘

- **独立复核要用「不同方法」**：同一套扫描器自己验自己不算数 ⇒ 换 `git grep` 两套口径 + 逐项核对跳过目录 / 大小写 / CI 清单才有效。
- **「令牌」与「文件名」是两种匹配口径**：令牌级无漏检 ≠ 没有任何引用 ⇒ 边界要按**语义**（能不能被用来绕过）来定，而不只是字符串。

另补一条本批查到的**工具坑**：`git grep` 对**非 ASCII 路径**默认做八进制转义（`docs/\346\211\207...`）⇒ 用它做「按目录过滤」会**失配**（本批实测：明明在允许区内的 `docs/批次/` 记录被当成越界命中）⇒ 复核脚本要么用 `-c core.quotePath=false`，要么改用文件系统遍历（本批的扫描器用后者）。
