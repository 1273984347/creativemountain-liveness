# B51 · 仓库级扫描器的**自证**（消除空转断言 + 封堵跳过目录盲区）

> 批次号 B51 · 日期 2026-11-09 · 主题：让 B48 的仓库级扫描器**能被证伪** —— 空集断言要有失败路径证据，跳过目录的盲区要显式登记。
> 前置：B50 的独立复核（`b27d23c`）留下三条遗留（T1 大小写 / T2 CI 空转 / 跳过目录）。

## 1. 起因：三个**确凿**缺口（不是推测，都有可复现证据）

| # | 缺口 | 证据 |
| --- | --- | --- |
| A | **CI 检查是空断言** —— 仓库无任何 CI 配置 ⇒ 那条「CI 配置不得引用标识」恒为空集 ⇒ 它可能**永远绿**（断言写错了也没人知道） | 5 条 CI 路径（`.github` / `.gitlab-ci.yml` / `.circleci` / `azure-pipelines.yml` / `Jenkinsfile`）**全部不存在** |
| B | **跳过目录里藏着已入库的源文件** —— `print/规则书叙述.md`（C10 要读的规则书叙述模板）因「整目录跳过」而**从未被扫描** ⇒ 令牌能藏在那里 | `git ls-files print dist` 计数 = **1**（B50 记「0」，不准确） |
| C | **标识匹配区分大小写** ⇒ 小写变体 / 全大写变体不命中 ⇒ 绕过的门道仍然开着 | B50 登记的 T1 |
| D | **说明漂移**（附带） | 测试文件头与用例标题仍写 `docs/**/*.md`；沉淀 README 写「十道门禁」；根 README 只列 9 道门、且含**不存在**的 `npm run build:themes`、门 ⑨ 写「720 局」而实际是 30 局 |

## 2. 做法

1. **扫描逻辑抽成共享模块** `tests/gates/repo-scan.ts` —— 正样本与负样本**共用同一实现**。
   ⚠️ 原实现把逻辑写死在测试文件里 ⇒ 负样本只能「另写一份近似实现」去测 ⇒ 那测的是负样本自己。**测错对象 = 等于没测**。
2. **CI 检查不再是空断言** —— 新增 `tests/gates/repo-selftest-scope-negative.test.ts`，**8 条隔离临时目录负样本**（含标识的 CI 配置必红、干净配置必绿）。
3. **跳过目录盲区** —— 例外白名单 `SCAN_EXCEPTIONS`（当前 = `print/规则书叙述.md`）把它拉回扫描范围；再加**集合守卫**：「跳过目录内的已入库文件集合 == 登记集合」⇒ 日后新增即红。
4. **大小写不敏感** —— 仍是**精确令牌**（不退化成子串，否则被文件名 `repo-selftest-scope.test.ts` 误伤）。
5. **盲区如实登记** —— 按仓内既有的 A5 机制（`tools/coverage-boundaries.mjs` + 规格 §9.3 覆盖边界表，**条数必须一致**，doc-sync C8 + A5 双重把关）新增 3 条：**9 条 → 12 条**。
6. **文档同步** —— 规格 §13.5 裁定行、沉淀 E87–E89、门禁清单失败排查、根 README 门禁表补全 ⑩–⑬、沉淀 README 门数、B50 记录追更正。

## 4. 遗留（如实登记）

| # | 现象 | 归属 |
| --- | --- | --- |
| T1 | **符号链接不跟随**（junction / symlink）⇒ 指向跳过目录外的链接目标不被扫描 | 有意：跟随链接可能成环；`node_modules` 里的链接本就不该扫 |
| T2 | 跳过目录里**未入库**的文件（未跟踪）仍不被扫 | 风险低：未入库 ⇒ 不会进版本 ⇒ 不是真源 |
| T3 | **二进制文件**（含字节标记）不扫 | 现实风险极低；已登记为覆盖边界 `scan-binary-and-large` |
| T4 | ~~**文件名**里的标识不命中（只扫内容）~~ | **已覆盖**（B51 补正）：文件名也纳入令牌检查 ⇒ 负样本 I/J 钉住；B50 已把允许区外的文件名引用改写为中文描述 |
| T5 | 隔离副本无 git 元数据 ⇒ 「已入库」守卫**显式 skipped** | 刻意：`node:test` 的 skip 状态可见（不是静默通过），且已登记进覆盖边界 |
| T6 | 跳过规则在**任意深度**生效（任意层级的同名目录都跳过），而例外清单只登记了顶层路径 | 盲审发现并已修：守卫改为按**每一段**判定（见 §7） |

## 5. 复盘

- **「空集」≠「有效」**：只跑「正例通过」时，一个恒为空集的断言和一个真正生效的断言**长得一模一样** ⇒ 任何可能为空集的检查都必须配**隔离负样本 + 正样本对照**。
- **盲区要显式登记 + 集合守卫**：跳过规则只写在实现里时，跳过集合会**静默扩大**（本批实测：跳过目录里已有一个真源文件）⇒ 登记为白名单 + 「实际集合 == 登记集合」断言 ⇒ 扩大即红。
- **负样本必须测被测实现**：逻辑内嵌在测试文件里时，负样本只能复刻一份 ⇒ 等于没测 ⇒ 逻辑必须住在双方都能 import 的模块里。
- **门禁在本批自证了一次**：给扫描器加 try/catch 后只跑了受影响的 16 项运行时测试（全绿）⇒ 提交前整跑门禁时**门 ①（tsc）红了**（`ReturnType<typeof readdirSync>` 命中了错误重载 ⇒ 类型退化成 `Dirent<NonSharedBuffer>`）⇒ 改用显式 `Dirent[]` 标注后恢复。⇒ **局部绿 ≠ 可提交**，类型门禁与运行时门禁互不替代（E90）。
- 已写入 `docs/沉淀/经验教训索引.md`（E87–E90）。

## 6. 独立盲审发现（verifier 子代理，提交后追加）

盲审用**与作者不同的方法**复核，抓到两处：

| # | 发现 | 处理 |
| --- | --- | --- |
| 1 | **守卫只比对顶层**：跳过规则在**任意深度**生效（扫描器遇到任意层级的跳过目录名就跳过），但守卫用「第一段 ∈ 跳过目录」判定 ⇒ 嵌套位置（如 `docs/批次/x/print/…`）的已入库文件会**漏过** | 守卫改为按**每一段**判定（`rel.split('/').some(seg => SKIP_DIRS.has(seg))`）⇒ 与扫描器语义对齐 |
| 2 | **并发假红**：门禁自检的「故意失败」探针写在 `tests/engine/negprobe.test.ts` ⇒ 名字匹配门禁②的 glob ⇒ **并行跑的另一个 test runner 会扫到它** ⇒ 别人的门禁瞬时假红（盲审与本批门禁并发时实测撞上） | 探针与隔离目录移到工程根 `.probe/`（不在 `tests/` 下 ⇒ glob 扫不到）；`runNodeTest` 扩展为支持**多个**位置参数（探针不在 glob 范围 ⇒ 显式点名）；`.gitignore` 登记 `.probe/` |

### 口径坑（复核时实测踩到）

| 坑 | 表现 | 解法 |
| --- | --- | --- |
| `git ls-files` 对**非 ASCII 路径**默认八进制转义并加引号 ⇒ 按目录过滤会**失配**（明明在允许区内的 `docs/批次/` 记录被当成越界命中） | 用 `-c core.quotePath=false`（本仓 `repoFiles()` / `trackedFiles()` 已带）；或改用文件系统遍历 |
| 注释里写 glob 路径含 `*/` ⇒ **提前终止 JSDoc 块** ⇒ 报看不懂的语法错 | 注释里避开 `*/` 连续（改措辞）；见 E91 |
