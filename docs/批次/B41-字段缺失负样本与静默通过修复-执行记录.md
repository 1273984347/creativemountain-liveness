# B41 · 补齐**基线 JSON 字段缺失**的负样本（并修一处静默通过漏洞）

> 批次号 B41 · 日期 2026-11-09 · 主题：消 B40 遗留 **T2**（未覆盖「JSON 合法但**字段缺失**」的半损坏）。

## 1. 先修漏洞，再补测试

⚠️ **原实现有静默通过漏洞**：比对用 `Math.abs(a - b) > 1e-9` ⇒ 某组缺 `fallback` 字段时 `bg[f]` 为 `undefined` ⇒ 差值算出 **NaN** ⇒ 而 `NaN > 1e-9` 为 **false** ⇒ 该组被判为「无差异」⇒ **半损坏悄悄通过**。

| 环节 | 改前 | 改后 |
| --- | --- | --- |
| 字段比对 | 直接算差值比大小 | **先校验字段存在且为有限数值** ⇒ 缺失/非数值单独归类 |
| 报错措辞 | 混在一处 | 区分「**字段缺失或非数值**」与「数值不一致」 |
| 判定 | NaN ⇒ 静默通过 | **显式判失败**（漂移即失败） |

## 2. 验证结果（2 条新负样本全绿，0.44s；既有 9 条仍全绿）

⇒ 发布检查的失败路径现共**九条**有负样本（漂移 / 门禁失败 / 重扫失败 / 产物缺失 / 基线缺失 / 基线损坏 / 基线组数不匹配 / 基线缺字段 / 产物缺字段）。

## 4. 复盘

- **NaN 比较会静默失败**：`Math.abs(a-b) > eps` 在字段缺失时为 false ⇒ 被当成「无差异」⇒ 比对前必须**先校验字段存在且为有限数值**。
- **半损坏是最隐蔽的一类失败**：文件在、JSON 合法，但内容缺一块 ⇒ 不校验就完全看不见 ⇒ 必须用负样本钉住。
