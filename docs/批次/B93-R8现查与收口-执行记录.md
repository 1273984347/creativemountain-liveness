## 4. 实测数据（8 人局 · 三组独立样本）

**读数解读**

- 开拓者族偏离**统计上显著**（z=18~24，CI 不含 0）⇒ 确实「略强」，但幅度只有记录线的约一半 ⇒ **不触发记录线 ⇒ 不动**。
- 开拓者族的**样本间抖动**达 +3.0 ↔ +8.6 ↔ +3.8pp ⇒ **单样本读数不可作决策依据**（单看 seed 9000 的先行者会误判为 +10pp 失衡）。

## 6. 复盘与经验沉淀

### 6.1 沉淀

- **E155**：**挂着要做的「平衡调整」也必须现查 —— 后续批次的改动可能已消解它的前提；且「三样本同向的稳定偏差」比「单样本的极端值」更可信**。本批实证：R8 登记的「开拓者 21.5%」是 **B75.2 当时**的读数，B77 之后已回落；三组独立样本下开拓者族合并偏离仅 +5.1~+7.3pp（未触发 15pp 记录线）⇒ 削弱一个并未失衡的身份属过度设计 ⇒ R8 关闭。根因：① 平衡类待办登记的是**某一时刻的读数**，而后续批次会改变整体格局 ⇒ 挂着不动 = 按过期事实做设计；② 单个 seed 基的读数波动可达 ±4~5pp ⇒ 拿单样本下结论必然不稳。做法：① 平衡调整类待办**开工前必须现查并用 ≥2 组独立 seed 基**；② 结论按「三样本是否同向 + 合并偏离 95%CI + 是否触发记录线」三者合取；③ **方向也要现查** —— 本批发现真正稳定偏弱的是**窃火者族**（三样本 -3.5~-3.9pp，CI 不含 0）⇒ 若将来调平衡，方向与 R8 原设想**相反**；④ 记录线（15pp）是**规格散文的人工判据**（`engine/core/balance.ts` 无身份常量）⇒ 不得表述为「锁」。
- 复用：**E153**（生成物入库却不被门读取 ⇒ 数值会悄悄过期）· **E152**（指针不许空转）· **E139**（回读校验）· **E143**（改完立刻跑）· **E93**（条数一致 ≠ 逐条对应）。
