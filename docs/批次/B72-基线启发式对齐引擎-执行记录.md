# B72 · 基线启发式对齐引擎（锁定回合的位移牌过滤）+ 重标定

## 1. 目标与范围

B71 修好枚举后，play 面还剩**一处两臂差异**：基线启发式的锁定分支仍按 `type !== 'motion'` 挑牌，
位移可以藏在 `utility` 类型与嵌套效果里（B66 的 `pending-cert-lock.test.ts` 已证）⇒ 启发式偶尔挑中
**引擎必拒**的牌，该回合空耗；模型臂从枚举拿到的都是合法牌。

本批把基线也改成 `cardHasMovement`（与引擎 / 枚举同源），并因此**重标定**基线：
`docs/balance-report.md` 重新生成，门 ⑫ 的同 seed 基线随之变化（阈值不动）。

## 2. 关键裁定

| # | 裁定 | 理由 |
|---|---|---|
| 1 | 位移判定统一用 `cardHasMovement`（引擎 / 枚举 / sim 三方同源） | 旧过滤是「形状判据」的残留；B66 已把引擎与枚举统一到效果级判定 |
| 2 | **重生成** `docs/balance-report.md`，而不是回退代码 | 这是修正缺陷导致的合法重标定；门 ⑨ 在 B70/B71 的「diff 为空」是为了防**掩盖回归**，与本批的主动重标定性质不同 |
| 3 | 门 ⑫ 阈值保持 14pp / 6.5pp **不动** | 新基线实测 9.9pp / 4.57pp（旧 8.6 / 3.38），仍在阈值内；改阈值会掩盖未来回归 |
| 4 | 门 ⑪ / ⑬ 的判据不动，只重跑 | 两者均有独立 PASS 线（偏差 ≤ 10pp；显著性与 B31 发布值一致），实测均通过 |
