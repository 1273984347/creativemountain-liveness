# B76 · 力竭机制：HP 归零的可逆惩罚 · 执行记录

日期：2026-11-14｜裁定来源：用户（更名「力竭」+ 三项实施裁定 + 两轮设计评审 + 计划评审）｜上游：§13.3「死亡/复活」延后项、B75 设计头部

## 1. 立项与更名

B76 的历史定义是「死亡/复活」。**用户裁定更名为「力竭」**：放逐下限恒为 3 的设计前提是「放逐是唯一出局通道」——若 HP 归零也出局，§5.6 下限逻辑 / §5.2 签印门槛 / §5.8 兜底排名全要重审（不是一个批次能收口）。力竭 = 可逆惩罚，放逐的社交分量保留，「打空」从虚变实。设计规格：`docs/superpowers/specs/2026-11-14-b76-力竭机制-design.md`（r1.1–r1.3 评审收口）。

**侦察战利品（规格 §0）**：① damage op 存在**暗杀分支**（hp=0 ⇒ `alive: false`，无下限保护无簿记）——与 §13.3「无死亡机制」矛盾，本批收口；② 险径扣血 clamp 不杀（两路径行为不一 → 统一）；③ poison 只写不读（裁定本批不修，归「死状态家族」批次）。
