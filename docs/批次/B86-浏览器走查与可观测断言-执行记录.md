## 3. 关键裁定（先定规则，再施工）

| # | 争议点 | 裁定 | 理由 | 落地位置 |
| --- | --- | --- | --- | --- |
| 1 | host 走查放哪执行 | **host 子项目自跑**（`npm run test:walkthrough`）+ 根仓**静态契约守卫**防腐化；**不进根仓门禁执行路径** | host 依赖不入库 ⇒ 根仓门禁在干净副本里起不了 vite；硬塞进去会让干净副本必然判红（B45–B52「门禁必须可跑」纪律） | `creativemountain-host/scripts/walkthrough.mjs`、`tests/gates/host-walkthrough-contract.test.ts`、覆盖边界 `host-walkthrough-outside-root-gate` |
| 2 | 走查用什么打开页面 | **必须 `file://`**，不得改 http 预览 | 产品承诺是「单文件 HTML 双击即玩、离线可用」；换成 http 预览等于把要验的东西换掉（B58 探针同款纪律） | `tests/e2e/ui-walkthrough.mjs` |
| 3 | 期望值写在哪 | **从 `theme.json`（`meta.name`/`terms.path`）与 `engine/scales.ts`（`boardLength`）派生**，脚本内不手抄 | 手抄的具体值会过期（E98）；单一事实源 ⇒ 主题/规模改动自动跟随 | 走查脚本的 `loadThemes()` / `scaleOf()` |
| 4 | 断言怎么算「可观测」 | 只认**渲染后的事实**：DOM 契约、真实盒子几何、console/page 错误、交互后的状态变化 | 源码形状 ≠ 页面没坏；「探针全绿 ≠ 版面没坏」正是本批的缘起 | 走查脚本的 `measure()` 与 `check()` |
| 5 | 错误路径挑什么非法值 | **用户真能造出来的那个**：小数 `1.5` 与空串（不是字母） | seed 框是 `type=number` ⇒ 字母类非法值用户根本输不进去，断言它等于断言一条用户碰不到的路径 | 走查脚本「错误路径[seed]」段 |
| 6 | 图示怎么改 | 改**生成器**（`figures/03-gate-panorama.mjs`）后重建两档，不手改产物 | 产物是生成物；手改产物下次重建即丢失（仓内「改了产物就要改生成器」） | `docs/图示/build/figures/03-gate-panorama.mjs` → 两档 HTML |

### 6.3 沉淀

- 本批踩到的坑 → 已沉淀到 `docs/沉淀/经验教训索引.md`：
  - **E139**：批量文本替换**工具返回成功 ≠ 文本落盘**（本批两处替换返回 `replacements: 1` 但文件实际未变）⇒ 必须回读校验。
  - **E140**：给错误路径挑非法值时，必须选**用户真能造出来**的那个（`type=number` 输不进字母）。
  - **E141**：负样本的隔离夹具必须落在**工作树之外**（否则并发跑 tsc 必假红 —— 本批修掉）。
  - **E142**：静态守卫必须比对**被测代码真正使用的那个常量**（比对死常量 ⇒ 假绿；本批盲审抓出）。
  - **E143**：批量/程序化改写之后要**立刻跑一次**，不能只看回读（崩溃与「断言红」必须分开看）。
- 通用化结论（跨项目可用的）：
  - 「浏览器验收」要分层归属：**能进根仓门禁的进**（无外部依赖），**依赖不入库的另立子项目入口 + 静态守卫**，并把分工**登记为覆盖边界** ⇒ 既不假装覆盖、也不让干净副本必然判红。
