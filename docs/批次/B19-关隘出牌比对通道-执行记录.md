## 2. 出牌比对通道的口径（B19 裁定）

| 项 | 口径 |
| --- | --- |
| 比什么 | **我出一张牌** vs **目标玩家的手牌顶**（**明牌**：对方牌面当场公开） |
| 怎么比 | 与对峙同款（§3.3）：先比颜色（红 > 黑）→ 同色比点数（`rank`，A=14 最大） |
| 胜 | **通过关隘**（写 `gate_<index>` 标记） |
| 败 / 平局 | **退 1 格并被封口**（`silence` +1）；**仍停在该关隘**，可再选付费 / 试炼 |
| 我方无此牌 / 目标为自己 / 目标已出局 | 动作**被拒**（状态不变） |
| 对方手牌为空 | **自动胜出**（直接通过） |
| 出牌 | **出牌即弃**（无论胜负，我方那张牌离手） |

**为何「明牌」而对峙是隐藏信息**：关隘是**公开的硬门槛**，比牌要当场公开；对峙是隐藏流程（双方各自选牌、同时揭晓）—— 两者不可混用。

**实现要点**：

- 退格用**显式实现**（与对峙 `duel.pushBack` 同款）—— 实测按预期传参调用 `move_backward` 算子**未生效** ⇒ 显式更可控。
- 粗筛发「我的每张牌 × 每个存活对手」的组合，引擎试跑负责拒掉无效组合。
- **AI 走比对通道**（手牌点数最大的一张 × 位置最靠前的对手）⇒ 保证该通道在模拟器里**可达**（若先走付费/试炼，关隘必被立刻解决 ⇒ 通道永不可达）。
- ⚠️ **但 AI 若「总是」先比牌，会改写资源经济**（胜则免灵枢过关）⇒ 实测**位次胜率极差从 <4pp 反弹到 5.5pp**，门 ② 的平衡回归判红。⇒ **AI 策略改为：付费优先 → 仅当付费不可用时比牌 → 试炼兜底** ⇒ 比对通道仍可达，但只在「付不起」时影响对局，平衡回到门禁口径（<4pp）。

## 5. 复盘与经验沉淀

- **动作类型存在 ≠ 行为已定义**：`COMPARE` 在 §6.3 的动作联合里躺了很久，却**从未有过行为语义** ⇒ 引擎无从实现，只能显式判拒。⇒ 动作契约要连同**行为口径**一起定，否则「有类型」给人「已实现」的错觉。
- **通道顺序决定机制可达性**：AI 若先走付费/试炼，关隘必被立刻解决 ⇒ 比对通道永不可达（**只写不读**）。⇒ 多通道并存时，要显式安排**可达性**（让每条通道都有机会被走）。
