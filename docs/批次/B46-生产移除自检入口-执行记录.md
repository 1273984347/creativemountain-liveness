# B46 · 生产脚本**彻底移除**自检入口（自检能力仅存在于 tests/）

> 批次号 B46 · 日期 2026-11-09 · 主题：消 B45 遗留 **T1**（生产脚本仍认 `--selftest` ⇒ 后门仍在生产侧）。

## 1. 改动

| 项 | 改前 | 改后 |
| --- | --- | --- |
| 生产脚本的自检识别 | 认 `--selftest`（与 env 双条件） | **彻底移除**：三个参数列入 `REMOVED` **拒绝清单** ⇒ 传入即**明确拒绝并非零退出**（不是静默忽略） |
| 自检能力所在 | 生产脚本 + tests/ 包装器 | **仅** `tests/gates/release-check-selftest.mjs`（tests/ 专用包装器） |
| 包装器实现 | 委托生产脚本的跳过能力 | **自建编排**：只验比对层 ⇒ 直接跑 `compare-scan-baseline.mjs`；需门禁/重扫步骤 ⇒ 委托生产脚本跑三步（未注入门禁时用**立即成功的假门禁** ⇒ 秒级） |
| 保留能力 | — | **路径注入**（`--gate=` / `--sim=` / `--scan=` / `--baseline=`）：只换输入、不跳过步骤 ⇒ 生产链不带 ⇒ 无法绕过 |

## 2. 回归验证（生产门禁不可绕过）

| # | 断言 |
| --- | --- |
| 1 | `package.json` 的 `release:check` / `release` **均不含** `--selftest`，`release` 以 `npm run release:check &&` 起头 |
| 2 | 生产脚本收到 `--selftest` / `--skip-gate` / `--skip-rescan` **任一** ⇒ 非零 + 「不支持自检/跳过参数」 |
| 3 | 这三个参数在源码里**只出现在拒绝清单**中，且存在明确拒绝逻辑 |
| 4 | 包装器自建编排且**沿用生产措辞** ⇒ 既有负样本断言不因迁移而漂移 |

⇒ `tests/gates` 共 **81 项全绿**（含 **20** 条负样本）；门禁 **13/13 全绿**。

## 3. 遗留（如实登记）

| # | 现象 | 归属 |
| --- | --- | --- |
| T1 | 生产脚本仍**保留**这三个字符串（作为拒绝清单内容） | 刻意：拒绝需要识别它们；保障来自「传入即非零」+ 生产链不带该标记 |
| T2 | 负样本的编排覆盖改为「子步骤 + 同一措辞」 | 编排传播的端到端覆盖由 B37 的实跑（真实漂移 ⇒ 发布检查红）承担；快速负样本聚焦子步骤 |

## 4. 复盘

- **「彻底移除」不能只是不再识别**：否则调用方传了参数会被**静默忽略** ⇒ 以为跳过了、其实没跳过 ⇒ 更危险 ⇒ 应列入拒绝清单并非零退出。
- **能力迁走后测试侧要自建编排**：不指望生产留后门 ⇒ tests/ 包装器自己决定跑哪几步，并**沿用生产措辞** ⇒ 既有断言不漂移。
