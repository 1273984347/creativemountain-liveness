### 6.2 沉淀

- **E144**：负样本不得依赖「工作树里恰好存在的生成物」（release 链 10 处 ⇒ 0）。
- **E145**：**「无横向溢出」不等于「没被压扁」** —— 容器可以窄到装不下自身文字（文字竖排碎裂）而**完全不产生溢出** ⇒ 只量容器宽度会漏判 ⇒ 必须量**子元素**的尺寸下限（页头按钮 ≥44px）并**看渲染图**（探针全绿 ≠ 版面没坏）。
- 既有教训复用：E142（守卫必须比对真正被使用的那个常量 ⇒ 本批守卫新增「TESTIDS 真被引用 ≥8 次」）；E127 的反面（**阈值不得下调** ⇒ 守卫卡「≥ 口径下限」，允许上调收紧、禁止改尺保绿）。

### 6.3 仍需后续处理

- **L-B87-1**：host 仅在 Chromium 实测；Safari/Firefox 的 `md:` 断点行为未验（无跨浏览器矩阵）。
- **L-B87-2**：flow3 排名表在 390 下靠表格内横向滚动承载（table 470px / 容器 306px）⇒ 文档级无溢出，可接受，但移动端表格体验一般（另批）。
- **L-B87-3**：窄屏导航条「暗色」按钮 40px（<44px 触控口径），它不是页头翻页按钮且未截断 ⇒ 不在当前断言口径内（可另批统一触控尺寸口径）。
- **L-B87-4（既有缺陷，非本批引入）**：**干净副本缺 `.git` ⇒ 依赖 git 元数据的用例必红**。`tools/repo-copy.mjs` 的 `repoFiles()` 用 `git ls-files` 取「已入库文件清单」，而 `docs/沉淀/clean-room-gate-check.mjs` 刻意只复制工作树文件（不带 `.git`）⇒ `tests/gates/mutation-samples.test.ts` 的隔离副本创建失败（`fatal: not a git repository`）⇒ 干净副本门 ② 必红。
  ⇒ 修法方向（交后续批次，本批不做）：要么让 `repoFiles()` 在**无 git 元数据**时回退到「按 `.gitignore` 规则扫描工作树」，要么让 clean-room 副本带一个**最小 git 仓库**（`git init` + 仅索引当前文件），要么把依赖 git 的负样本排除出 clean-room 的门 ② 并如实登记。
  ⚠️ 本批**不修**的理由：会动既有 `repo-copy.mjs` 的核心复制语义（它同时服务门 ② 的隔离副本），风险高于本批收益；且与本批目标（host 侧两项修复 + release 负样本去生成物依赖）无关。
