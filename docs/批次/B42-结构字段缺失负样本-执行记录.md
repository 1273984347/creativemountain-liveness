# B42 · 补齐**基线结构字段（groups / seedBase）缺失**的负样本

> 批次号 B42 · 日期 2026-11-09 · 主题：消 B41 遗留 **T2**（比对只校验指标字段，不校验结构字段 ⇒ 报错不精准）。

## 1. 改动

| 项 | 改前 | 改后 |
| --- | --- | --- |
| 结构校验 | 无 ⇒ `groups` 缺失会走到 `doc.groups ?? []` 的**空数组**分支或抛错；`seedBase` 缺失 ⇒ 分组键拼成 `reserve@undefined` ⇒ 只表现为「缺少该组」 | 比对前加**一层结构校验**：`groups` 必须是数组、每组必有数值型 `reserve` / `seedBase` 与全部指标字段 ⇒ 报错**直接点名**（如 `groups[0].seedBase`） |
| 报错分层 | 混在一层 | 区分「**结构**字段缺失或非数值」与「**指标**字段缺失或非数值」 |

## 4. 复盘

- **报错要能区分「结构坏了」与「数据漂移」**：结构字段缺失若只表现为「缺少该组」⇒ 运维会往数据方向查 ⇒ 白排查。
- **校验分层**：先结构（容器/关键字段）再数值（逐组差值）⇒ 每层给不同措辞 ⇒ 定位一次到位。
