# B45 · 绕过入口迁至 tests/ + 验证生产发布检查无法绕过门禁

> 批次号 B45 · 日期 2026-11-09 · 主题：消 B44 遗留 **T1**（绕过开关虽上锁但**仍在生产脚本里**）。

## 1. 改动

| 项 | 改前 | 改后 |
| --- | --- | --- |
| **绕过入口位置** | 在生产脚本 `tools/release-check.mjs` 里（靠环境变量约束） | **迁到 `tests/gates/release-check-selftest.mjs`**（tests/ 专用包装器）⇒ 6 个负样本文件改用它 ⇒ env 注入不再散落 |
| **生产脚本的跳过条件** | `CM_SELFTEST=1` 单条件 | **双条件**：`CM_SELFTEST=1` **且**显式传 `--selftest` ⇒ 缺任一 ⇒ **直接拒绝执行**（不静默继续） |
| **生产发布链** | `npm run release:check`（无参数） | 不变 ⇒ **不带 `--selftest`** ⇒ 结构上无法绕过 |

## 2. 「生产无法绕过」的三层验证（4 条负样本）

| # | 断言 |
| --- | --- |
| 1 | `package.json` 的 `release:check` / `release` **均不含** `--selftest`，且 `release` 以 `npm run release:check &&` 起头 |
| 2 | 即便设了 `CM_SELFTEST=1`，**生产脚本也拒绝**跳过（无 `--selftest`）⇒ 非零 + 不静默继续 |
| 3 | 即便传了 `--selftest`，缺 `CM_SELFTEST=1` 也拒绝 ⇒ **双条件缺一不可** |
| 4 | 生产脚本**不内置无条件自检模式**；包装器负责设 env 与传标记 |

## 3. 验证结果

- `tests/gates` 共 **81 项全绿**（含 **20** 条负样本）。
- 门禁 **13/13 全绿**。

## 4. 遗留（如实登记）

| # | 现象 | 归属 |
| --- | --- | --- |
| T1 | 生产脚本**仍认** `--selftest` 标记（与 env 组成双条件） | 刻意保留：否则 tests/ 包装器无法转达自检意图 ⇒ 真正的保障来自「生产链不带该标记」+「双条件」+ 4 条负样本 |
| T2 | 绕过能力在**测试侧**仍存在（包装器） | 有意：它只服务负样本；生产链不经过它 |

## 5. 复盘

- **后门不要留在生产脚本里**：哪怕要环境变量，也应把「跳过」能力迁到**测试侧** ⇒ 生产工具只剩「全量执行」一条路。
- **上锁用双条件**（环境变量 + 显式标记）且**拒绝而非静默继续** ⇒ 误用立刻失败，不会悄悄削弱检查。
- **「无法绕过」要靠负样本证明**，不能只靠注释与约定。
- 已写入 `docs/沉淀/经验教训索引.md`（E81）。
