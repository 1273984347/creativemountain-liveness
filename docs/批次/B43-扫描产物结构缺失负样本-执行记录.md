# B43 · 补齐**扫描产物**缺 groups / reserve 的负样本

> 批次号 B43 · 日期 2026-11-09 · 主题：补齐发布检查失败路径在**扫描产物侧**的结构缺失形态。

## 1. 改动

| 项 | 做法 |
| --- | --- |
| **产物侧结构负样本** | 新增 `tests/gates/release-scan-structure.test.ts`：产物缺 `groups` / 某组缺 `reserve` / `groups` 为**空数组** ⇒ 均断言非零 + 点名 |
| **空数组单独措辞** | 结构校验新增「`groups` 为空数组（没有任何分组）」⇒ 与「多出该组」区分开（后者会误导成数据漂移） |

## 2. 验证结果（3 条全绿，0.65s）

| 用例 | 断言 |
| --- | --- |
| **产物缺 groups** | 非零 + 「扫描产物结构字段缺失或类型错误：groups」 |
| **产物某组缺 reserve** | 非零 + 「扫描产物结构字段缺失或非数值」+ 点名 `reserve` |
| **产物 groups 为空数组** | 非零 + 「groups 为空数组（没有任何分组）」 |

⇒ 失败路径覆盖：B38 漂移 · B39 门禁/重扫/产物缺失 · B40 基线缺失/损坏/组数不匹配 · B41 指标字段缺失 · B42 基线侧结构缺失 · B43 产物侧结构缺失 ⇒ 共**十五条**有负样本。

## 4. 复盘

- **同一类故障要在「两个输入通道」上各测一遍**：基线坏与产物坏是两种故障 ⇒ 只测一侧 ⇒ 另一侧仍是未知。
- **「空」是第三种坏法**：字段在、类型对、**内容空**（`groups: []`）⇒ 不单独措辞会被误报成「多出该组」（误导成数据漂移）。
