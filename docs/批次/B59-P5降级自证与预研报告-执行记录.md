## 6. 复盘与经验沉淀

- **三种固定形状是消费方的契约**：降级脚本的输出形状必须**逐字固定**（三种），否则消费方要写第四种解析分支 ⇒ 兜底也要落回既有形状（附状态码）。
- **「无服务」不是失败**：退出码恒 0 ⇒ 门禁与流水线才能把「sidecar 不在」当**正常态**而不是错误。
- **常驻负样本可以进门禁，前提是它不依赖被测对象**：用**必定失败的输入**（端口 1）自证「降级路径真的会走」⇒ 在任何机器上都成立。
- **判据不下调，缺读数就写「未跑」**：P2 的 CPU 分支无读数 ⇒ 如实写「CPU 路径未测」而非含糊地写「达标」。
- 已写入 `docs/预研/2026-11-08-laya-sidecar.md`（§5）。
