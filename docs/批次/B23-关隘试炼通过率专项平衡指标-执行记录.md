# B23 · 关隘试炼通过率专项平衡指标（t_wind / t_star）

> 批次号 B23 · 日期 2026-11-08 · 主题：补 B22 登记的 **T1** —— 骰子型试炼（`t_wind` / `t_star`）的通过率**没有任何量化指标**；本批补齐并**纳入门禁**。

## 1. 方案

| 环节 | 做法 |
| --- | --- |
| **可机器统计的日志** | 试炼日志条目加**结构化字段** `trialId` / `trialPassed`（`kind='trial'`）⇒ 平衡模拟直接统计，**不解析中文文案**（规格 §6.2 同步登记） |
| **机制层硬判据** | **定向长跑**：对每张**骰子型试炼**抽 ≥ 400 次（走**生产同一条代码路径** `resolveGate(state, seat, 'trial')`，不另写模拟器副本）⇒ 通过率与**理论期望** `(faces-amount+1)/faces` 偏差 ≤ **10pp** |
| **对局层证据** | 24000 局真实模拟：每张试炼牌的**抽取次数 / 通过次数 / 通过率 / 每千局抽取** ⇒ 只作**可达性证据**，**不作硬阈值**（事件偶发 ⇒ 样本不足） |
| **门禁第 ⑪ 道** | `node tests/sim/run.mjs --trial-rate --check`：① 通过率偏差 ≤ 10pp；② 失败必写「本关改为付费」；③ **日志结构化字段与引擎判定一致**（负样本锚点：删字段 ⇒ 必红） |
| **附带修复** | `engine/core/state.ts` 的 `LogEntry` 被**完整复制了两份**（复制粘贴遗留，靠 TS 声明合并侥幸无害）⇒ 合并为一份 |

## 3. **重大发现（如实登记）**：试炼通道在真实对局中几乎不被使用

| 指标 | 数值 |
| --- | --- |
| 24000 局里试炼通道被使用 | **9 次**（每千局 **0.375** 次） |
| 被抽到过的牌 | 6 张（`t_empty` / `t_oath` / `t_silent` / `t_star` / `t_sutra` / `t_vital`，各 1–3 次） |
| 一次都没出现的牌 | **6 张**（`t_mantra` / `t_mirror` / `t_stone` / `t_sword` / `t_toll` / `t_wind`） |
| 根因 | AI 关隘策略 = **灵枢够就付费**（`autoResolveGate`）⇒ 灵枢充足时从不选试炼 |

⇒ **B22 把 12 张牌全部改造成挑战型**，而真实对局里玩家几乎走不到试炼通道；
⇒ 因此「试炼的平衡」目前只是**机制层**的平衡（定向长跑），**尚未**体现在真实对局里；
⇒ 本批不擅自改 AI 策略（会改变整体平衡、需重新标定），登记为遗留 **T1**，建议独立批次处理。

## 4. 遗留（如实登记）

| # | 现象 | 归属 |
| --- | --- | --- |
| T1 | AI 关隘策略「灵枢够就付费」⇒ 试炼通道在真实对局中 24000 局仅 9 次 ⇒ 试炼机制近乎不可见 | **建议独立批次**：让 AI 按**资源余量 / 关隘难度 / 期望收益**选通道（如「付完仍余 ≥ N 灵枢才付费」），并重跑平衡标定 |
| T2 | 真实对局侧无法给通过率硬阈值（事件偶发 ⇒ 样本不足 ⇒ 阈值会永远红或 flaky） | 已分治：**机制层定向长跑给硬判据**，对局层只报可达性与使用率（规格 §9.2 已改写） |
| T3 | 定向长跑每次都要**全新局面**（试炼无论成败都写标记 ⇒ 同一局面不可复测）⇒ 3200 次 `installTheme` | 成本可接受（门 ⑪ 约 0.3s）；样本量若再增，需抽公共「场景工厂」 |

## 5. 复盘

- **指标要分「机制层」与「对局层」**：偶发事件在对局层样本不足 ⇒ 用它当阈值要么永远红、要么 flaky ⇒ 硬判据必须放在**定向长跑**（机制层），对局层只报可达性与使用率。
- **可达性统计要遍历全集**：报告只遍历「出现过的事件」⇒ 一次都没出现的 6 张牌被隐藏 ⇒ 读者会误以为都健康。⇒ 遍历**数据源全集**（12 张牌全列，0 次也写出来）。
- **seed 必须含主题 id**：四主题共用一条随机轨迹 ⇒ 统计上不是 4 个独立样本（四主题数值会一模一样）。
- **使用率也是平衡指标**：机制「实现了」不等于「被使用」⇒ 除通过率外必报**每千局使用次数**；使用率 ≈ 0 ⇒ 该机制在真实对局里形同虚设。
- **纸面口径要与实测对账**：初稿规格写「每张牌抽取次数须 > 0」⇒ 实测 6 张牌 0 次 ⇒ 该口径**不可满足** ⇒ 改写为「对局层只作可达性证据，硬判据由定向长跑承担」。
