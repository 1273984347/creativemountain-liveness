# B24 · 关隘通道余量规则（付费后仍有余量才付费）

> 批次号 B24 · 日期 2026-11-08 · 主题：消 B23 登记的 **T1** —— AI 关隘策略「灵枢够就付费」⇒ 试炼通道在真实对局里几乎不被使用（B23 实测 24000 局仅 **9 次**，12 张试炼牌里 6 张一次都没出现）。

## 1. 方案

| 环节 | 做法 |
| --- | --- |
| **余量判据（单一事实源）** | 引擎新增 `GATE_RESOURCE_RESERVE = 2` 与纯函数 `canPayGateWithReserve(resource, fee)` ⇒ **付费后仍余 ≥ 2 灵枢**才算体面付费；`advance.ts`（要不要先比牌）与 `autoResolveGate`（付费还是试炼）**共用**同一判据 |
| **AI 通道顺序** | ① 能体面付费 ⇒ 付费；② **完全付不起** ⇒ 先走出牌比对（B19 口径不变：比对通道只在付费通道不可用时影响对局 ⇒ 位次极差不反弹）；③ 付得起但会掏空 ⇒ 走**试炼**（博一把：通过有额外收益，失败 ⇒ 本关改为付费） |
| **引擎层加固** | 「已因试炼失败而改为付费」的关隘 ⇒ **拒绝**再试炼、**拒绝**再出牌比对（此前只有粗筛 `legal.ts` 拦 ⇒ 脚本/测试可绕过） |
| **玩家侧不受影响** | 余量规则只约束 **AI 自动解算**；玩家显式选付费照常按标价扣灵枢（即使掏空余量） |
| **门禁强化** | 门 ⑨ 新增断言「**12 张试炼牌全部可达**」（每张牌都必须在真实对局中被抽到过）⇒ 防策略再退化 |

## 3. 观察（如实登记）

- **非骰子型试炼的通过率高达 73%–100%**（`t_empty` 100% · `t_toll` 99.8% · `t_stone` 99.7% · `t_mantra` 99.3% · `t_sword` 98.2% · `t_mirror` 91.2% · `t_sutra` 85.0% · `t_silent` 78.0% · `t_vital` 73.5%）⇒ 「`has_card` 类」判定在真实对局里几乎必过 ⇒ 试炼通道对 AI 而言**风险很低** ⇒ 这才是使用率暴涨的直接原因。
  ⇒ B22 的「挑战型」改造在**骰子型**上确实有挑战（75% / 45%），在**条件型**上仍近乎稳过 ⇒ 若要更强挑战须改判定谓词（独立批次）。
- **位次极差是既有偏差**：8 人局「独赢局」口径下改前 4.5pp、改后 4.2pp ⇒ §9.2 的「< 4pp」**改前即不满足**（该口径样本小、噪声大）⇒ 本批未恶化，但口径需单独校准。
- **门禁出现过一次假红**：`tests/gates/pdf-normalize.test.ts` 归一化哈希不一致 ⇒ **单跑必绿、复跑必绿** ⇒ Edge 渲染时序（读到未稳定文件）⇒ 与本批改动无关，登记为遗留 T3。

## 4. 遗留（如实登记）

| # | 现象 | 归属 |

| T1 | 非骰子型试炼通过率 73%–100% ⇒ 「挑战型」的挑战性主要落在骰子型上 | **建议独立批次**：为条件型试炼改更严格的谓词组合（如「同色 2 张」而非「有 1 张」）⇒ 需主题包数据变更 + 平衡重标定 |
| T2 | §9.2「位次胜率极差 < 4pp」在 8 人局独赢口径下**改前即不满足**（4.5pp）⇒ 口径与样本量不匹配 | **建议独立批次**校准口径（定义或样本量基准），本批只如实登记 |
| T3 | `pdf-normalize.test.ts` 在并发高负载下偶发假红（Edge 渲染时序） | 建议加固 `waitForStableFile`（加长退避 + 重试）；本批未改（不属本批范围） |
| T4 | 余量阈值 **2** 为单点取值（未做多值扫描） | 若要更精细的「使用率 / 难度」权衡，须**逐档分别标定**（不存在统一比例时不能一刀切） |

## 5. 复盘

- **「机制实现了」≠「被使用」**：B22 刚做完的 12 张挑战型试炼，真实对局 24000 局只被用 **9 次**（6 张一次都没出现）⇒ B23 的指标上线才暴露出这件事 ⇒ 机制类改动的验收必须含**使用率**维度，且**先看使用率、再看通过率**。
- **策略判据必须单一事实源**：付费门槛同时出现在「比牌时机」与「付费/试炼选择」两处 ⇒ 抽成 `canPayGateWithReserve` 纯函数 + 常量，避免改一处忘一处。
- **余量规则的真实语义**：试炼失败 ⇒ 改为付费 ⇒ 最终仍要付费 ⇒ 余量不是「省下来」，而是「**先博一把**」（试炼通过有额外收益）⇒ 对 AI 是**期望收益**决策，不是节俭。
- **阈值口径要与样本量对账**：8 人局独赢口径样本小 ⇒ 极差在 3.5–4.5pp 波动 ⇒ 用固定 4pp 卡它会长期「改前就红」⇒ 工具改为默认报告模式、`--strict` 才判红。
