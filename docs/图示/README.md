# 图集 · 技术图（8 张 × 2 档）

本目录是《创界山·活人认证》的**技术图集**：把仓库里原本只有文字与表格的关键结构，
画成可离线打开的自包含 HTML。

- 产物：每张图两档 —— **文档档**（960×600，贴 README / 规格正文）与**投屏档**（1280×720，评审投屏）。
- 形态：单文件 HTML，内联 SVG + CSS，除 Google Fonts 外无外链，**离线可开**。
- 生成：`docs/图示/build/` 下的生成器 + 坐标约定，见 [build/README.md](build/README.md)（图集构建契约）。

## 构建与自查

```bash
node docs/图示/build/diagram-build.mjs                 # 全量重建 16 份产物
node docs/图示/build/diagram-build.mjs --only <slug>   # 只重建某一张
node docs/图示/build/verify.mjs                        # 统一验收：无障碍/正交/留缝/栅格/预算/两档一致
node docs/图示/build/shoot.mjs                         # 渲染成 PNG 并做越界量测
node docs/图示/build/shoot.mjs --only <文件名片段>
```

- 产物是**生成物**：改图请改 `build/figures/*.mjs`，然后重跑构建器。
- `shoot.mjs` 把真实浏览器渲染结果搬成 PNG 落在 `assets/`，供人工目视复核 ——
  探针报「溢出 0 处」不等于图能看，版面失衡只能靠看图发现。
- 截图 PNG 是复核材料，不入库（构建产物可随时重新生成）。
