# 沉淀区 · 统一知识库入口

本目录收纳**可沉淀、可复用**的全部know-how：方法论、门禁纪律、经验教训、模板与取证脚本。
过程档案（每批的目标 / 裁定 / 验收数据 / 提交）保存在 `docs/批次/`，由 [批次导航.md](批次导航.md) 分类索引。

> **生效代码不搬到这里** —— 搬动会破坏门禁路径与文档交叉引用；本目录只做**索引、范式与取证工具**。
> **2026-11-11 B73 统一整理**：经验教训索引按五类重组（124 行逐字保留、仅调整分组与排序）、新增批次导航、本 README 改为统一入口。

## 六、维护规则

1. **新经验先进批次记录**（过程 + 数据），再把**已通用化**的结论补进 `经验教训索引.md`：E 编号 = 现有最大 + 1；放进对应分类的表格末尾。
2. **索引行文字不改**：只允许追加 / 分组；需要更正时在「落地」列加注记（如「B72 更新」），不重写历史行。
3. **新增沉淀文档**必须在本 README 的「目录索引」登记，并归入上表五类之一。
4. **生效代码与门禁脚本不搬动**；如需移动被门禁引用的路径，必须同步改 `tools/gate.mjs` 并跑全门禁。
5. 本目录与代码冲突时，以代码 + `docs/批次/` 的实证为准，并回填本目录。
