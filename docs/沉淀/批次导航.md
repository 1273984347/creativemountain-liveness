# 批次档案导航（过程记录）

> 用法：`docs/批次/` 是**过程档案**（每批的目标、裁定、验收数据、提交）；本文件按主题归类，便于按问题回溯。
> ⚠️ 分类按**文件名标题关键词**自动归类（跨类批次只归首要一类），仅供导航；新增批次后按同一规则追加。
> ⚠️ **单位定死：一行 = 一个档案文件**（不是"批号"——B18/B19 各有三份记录，同一批号占多行）。
>   三个数（各小节标题的括号数、分类总览的批次数与合计、实际行数）必须互洽，复算入口：
>   `node tools/presets/batch-nav-count.mjs`（只读，不互洽就 exit=1 并点名差在哪）。
>   **别手改总数**：加行的正确顺序是「先加行 → 跑脚本 → 按它报的行数改声明」。
>   B80 T8 首跑时这里写的是 76，而行数 77 / 文件 78——76 是一个没有定义的单位留下的旧数。
> 「一句话结论 / 关键读数」由只读子代理通读每份记录抽取、并经抽样核对（B9/B18/B23/B69）；数字以记录原文为准。
