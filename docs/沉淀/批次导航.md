# 批次档案导航（过程记录）

> 用法：`docs/批次/` 是**过程档案**（每批的目标、裁定、验收数据、提交）；本文件按主题归类，便于按问题回溯。
> ⚠️ 分类按**文件名标题关键词**自动归类（跨类批次只归首要一类），仅供导航；新增批次后按同一规则追加。
