## 结论（2026-11-11 本地实测 · 全部取自 `docs/预研/data/b70-face-arms.json`，无手填估计值）

### play 面

1. **判定**：「该面模型劣于启发式，保持贪心」。
2. **配对计数**：b=105、c=55、χ²=15.00625 **> 临界 3.841** ⇒ 差异显著，且方向为负（模型输多赢少）。
3. **座0 胜率**：基线 31.0% → 模型 18.5%（掉 12.5pp）。
4. **胜者变化率**：40.0%（b+c=160/400 局 —— 出牌是高频面，改道改动了近半对局的胜者）。
5. **模型调用**：2487 次；延迟 p50=57ms / p95=71ms。
6. **回落 0 次 / 空候选 3637 次**（空候选 = 该面无候选的时刻，未计入 calls；fallbacks=0 ⇒ 模型每次都被问到且都答了合法 key）。
7. **兜底局数**（终局走距峰顶格数结算）：基线 28 → 模型 33；**平均回合** 13 → 13。
8. **anomalies = 0**。

**读法**：出牌面的启发式（按效果强度 + 平价优先的 `pickPlayableCard`，叠加 0.16/0.75/0.85 的行动分段）显著强于本模型的逐次选择 —— 模型只看到题面文本，不知道「行动分段」这张随机表，逐次把概率资源花在了错误的时机上。**保持贪心，不接入。**

### council 面

1. **判定**：「未检出改善」。
2. **配对计数**：b=74、c=71、χ²=0.027586 **< 临界 3.841** ⇒ 差异不显著。
3. **座0 胜率**：基线 31.0% → 模型 30.3%（掉 0.7pp，噪声量级）。
4. **胜者变化率**：36.3%（改票改的是「谁被流放」，传导长 ⇒ 变化多但方向随机）。
5. **模型调用**：400 次；延迟 p50=60ms / p95=69ms。
6. **回落 0 次 / 空候选 4859 次**。
7. **兜底局数**：基线 28 → 模型 15；**平均回合** 13 → 13。
8. **anomalies = 0**。

**读法**：山议投票与启发式（点数最大目标）基本等价。**保持贪心，不接入。**

### certify 面

1. **判定**：「未检出改善」。
2. **配对计数**：b=25、c=32、χ²=0.631579 **< 临界 3.841** ⇒ 差异不显著（b/c 都小 —— 认证动作本身低频）。
3. **座0 胜率**：基线 31.0% → 模型 32.8%（升 1.8pp，但未过显著线）。
4. **胜者变化率**：14.2%（三面最低 —— 认证动作只在待认证时刻发生）。
5. **模型调用**：553 次；延迟 p50=61ms / p95=68ms。
6. **回落 0 次 / 空候选 4876 次**。
7. **兜底局数**：基线 28 → 模型 59（改签印时机改变了终局路径）；**平均回合** 13 → 13。
8. **anomalies = 0**。

**读法**：方向为正但样本不足（b+c=57，按 χ² 需要 ≈80+ 不一致对才过线）。若未来要复验，应**只对 certify 面扩样**（提高 SEEDS 即可，机制不用动）；在此之前**保持贪心，不接入**。

### 固定声明

1. 本批**只评估不接入**：`policy` 缺省 undefined、sim CLI 无新开关、门 ⑨ 基线未动。三面判定均为「保持贪心」或「未检出改善」⇒ **无任何一面触发「值得接入，另立批次做门 ⑨ 重校准」的分支**。
2. 随机流口径注记：模型臂在改道命中时不再消耗启发式那次 `s.rng.next()` 判定 ⇒ 两臂随机流自首个分歧起分叉；配对比较仍成立，因为同 seed 起点相同。
3. 服务口径：`device=cuda`，总就绪 50.81s；评估总耗时约 3.3 分钟（远低于 30 分钟/面预算，无一面中断）；跑完即停，端口 8711/8712 复验均为 `000`（无响应，无残留进程）。
4. 复跑命令：先 `npm run sidecar:laya`（或 `node tools/laya-sidecar/up.mjs --weights D:/<local-libs>/laya-multilingual/model.safetensors`），就绪后 `npm run eval:faces`；无服务时 `npm run eval:faces` 打印 SKIP 且退出码 0。
